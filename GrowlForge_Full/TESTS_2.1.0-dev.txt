GrowlForge 2.1.0-dev architecture verification
================================================

Reference: uploaded GrowlForge 2.0.3 source, rebuilt in Release mode.
Candidate: modular 2.1.0-dev source, built in Release mode.

Audio regression
----------------
- 48 kHz, stereo float32, 128-sample blocks.
- Eight 3-second scenarios covering:
  neutral pass-through; Drive; Drive/Grind/Fuzz/Harmonic Bias;
  Gate/tone shaping; motion/dynamics; Auto-Gain/output routing;
  broad x2 stress settings; Drive 10 with x2 enabled.
- Result for every scenario:
  max absolute difference = 0
  RMS difference          = 0
  non-zero sample count   = 0

- Parameter count: 36 in both builds.
- IDs, flags, names, modules, ranges and defaults: identical.
- Only the descriptor version string changed to 2.1.0-dev.

------------------
